# CarbonSite UI/UX Revamp Prompts

Source scan: MotionSites sections page, which presents a premium library of AI design prompts, hero sections, animated backgrounds, gradients, and templates. The prompts below adapt the relevant patterns to CarbonSite without copying their private section copy or implementation.

## Design Direction

Build CarbonSite as serious construction-climate operations software: modern, precise, evidence-led, and movement-rich without looking like a generic AI SaaS template. Use real product surfaces as the hero asset: dashboard analytics, mobile evidence capture, route distance, review queue, audit trail, and report packs.

Avoid a one-note green palette. Keep the brand green as a functional signal, but pair it with off-white, slate, steel, amber warnings, blue route/evidence accents, and restrained dark panels.

## Page Prompts

### Home

Create an asymmetric SaaS hero for UK construction carbon operations. Left side: sharp headline, pilot CTA, trust signals, and proof metrics. Right side: layered live product composition showing route distance, OCR evidence, field submissions, and emissions analytics. Use subtle grid motion, soft depth, and no decorative blobs.

### Product

Design a workflow spine page that moves from mobile capture to review, calculation, snapshots, and reporting. Use stacked horizontal panels with status chips, document thumbnails, route lines, and audit events. Each section should feel like a working product module, not marketing cards.

### Dashboard

Design an executive operations cockpit for construction emissions. Include scope totals, submission health, mobile capture queue, social value initiatives, top emission categories, route-distance coverage, report pipeline, and audit exceptions. Prioritize scannability, dense data hierarchy, and fast action links.

### Members And Access

Design an access-control command centre. Show team roles, pending invites, mobile worker onboarding, project/site assignment, invite links, and audit-safe removal. Use a stepper-style workflow: invite, accept profile, assign project, capture evidence, review submissions.

### Mobile App

Design a field-worker capture flow for noisy site conditions. Emphasize camera-first evidence capture, OCR extraction confidence, manual correction, offline queue, GPS context, pickup/delivery postcodes, and submission status. Use large controls, explicit states, and low-light-friendly contrast.

### Reports

Design a board-reporting workspace with snapshot status, downloadable artefacts, report types, calculation provenance, failed generation recovery, and reviewer sign-off. Use a premium document-control visual language: page thumbnails, checksums, version badges, and audit history.

### Security

Design a trust-and-controls page for tenant isolation, RBAC, evidence storage, audit logs, route provenance, and mobile access control. Use structured control rows and proof panels instead of generic shield-card marketing.

### Resources

Design an editorial knowledge hub for pilot setup, field evidence standards, route distance, OCR capture, supplier data, and reporting governance. Use practical guides, checklists, and implementation paths for construction teams.

### Contact

Design a pilot-planning page that collects project context: organisation, reporting period, sites, expected field workers, document types, supplier files, and route postcode coverage. Make the form feel like project scoping, not a generic sales lead form.
