## Companies House (supplier lookup)

Local spend → Add a supplier can search the Companies House public register (`api.company-information.service.gov.uk`, free API key in `COMPANIES_HOUSE_API_KEY`). Data is public sector information under the Open Government Licence v3.0; the attribution "Contains public sector information licensed under the Open Government Licence v3.0. Source: Companies House." is shown beside the result. Only the typed company name or number is sent. Nothing is stored beyond what the person saves on the supplier (name, postcode). Companies House's API terms limit the rate to 600 requests per 5 minutes per key; our route allows 30 a minute per user.

## Environment Agency public registers (carrier, permit and exemption checks)

Checked 26 October 2026 from the licence text shipped with the Agency's bulk download and from search summaries; the licence pages themselves could not be opened from our environment, so the position below is not confirmed. The carriers, waste operations and exemptions registers are offered under the [Environment Agency Conditional Licence](https://www.gov.uk/government/publications/environment-agency-conditional-licence/environment-agency-conditional-licence), which tells the user to check each dataset's own conditions first. The carriers dataset's special conditions read: use for "internal or personal purposes"; sublicensing only under a written licence carrying the same terms; "the period of permitted use is one year"; and use restricted "to protect the rights or confidentialities of others". Search summaries say the same conditions apply to the API. Attribution on the dataset record: "Contains Environment Agency information © Environment Agency and/or database right" (the record quotes the year 2022).

What we do: one live lookup per registration, permit or exemption number (`lib/waste/carrier-register.ts`, `permit-register.ts`); only the number leaves our server; the result is kept on the document the person checked. We do not bulk-load or mirror the register; the only register data we keep is the result of a check the person ran (holder name, tier, status, expiry) on that document. The bulk file also holds sole traders' names and addresses, which we never load. The attribution is shown beside each result.

Checked against live responses (26 October 2026, fetched through TinyFish because the build container's proxy blocks outbound hosts): the `registrationNumber` filter returns exactly the one matching item on all three registers (exemption numbers need the slash URL-encoded, `EXP%2F...`); with no filter a call returns the first 2000 items (`meta.limit` 2000, about 4.9 MB for carriers), and `_limit` is honoured, so the code must always send the filter and never a bare call. `meta` carries `licence` (the Conditional Licence URL in `REGISTER_LICENCE_URL`), `comment: "Beta service"` and no attribution text, so the attribution wording stays ours. Every field path read by `parseRegister()` and `parsePermit()` exists in the payloads: carriers `registrationNumber`, `expiryDate`, `tier.label`, `registrationType.label`, `holder.name`, `holder.companyNumber`; permits `status.comment`, `site.premises`, `site.siteAddress.address`, `site.siteType.description`; exemptions `exemption[].expiryDate`, `exemption[].registrationType.notation` and `site[]` as an array.

Open: whether showing lookups to customers of a multi-tenant service is "internal use", whether the one-year period renews and covers the API, and what attribution wording the Agency wants. Ask the Environment Agency in writing and record the answer here. Until then no code or copy may say the register's data is licensed for commercial reuse.
